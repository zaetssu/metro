# Метро Москвы: Поиск кратчайшего пути

Консольная утилита для расчёта времени и построения оптимального маршрута по Московскому метрополитену с использованием алгоритма Дейкстры.

## Запуск
```bash
python -m main path --from "Арбатская (Арбатско-Покровская)" --to "Таганская (Кольцевая)"
python -m main time --from "Арбатская (Арбатско-Покровская)" --to "Таганская (Кольцевая)"
